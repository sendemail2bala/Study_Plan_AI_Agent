# Study Plan AI Agent

A beginner-friendly Python + Streamlit project that demonstrates the components of an AI agent.

## What it does

- Collects a student's subjects, available study minutes, plan length, start date, and goal.
- Builds a study schedule using a Python function (the tool).
- Shows the schedule in a web UI.
- Exports the result as JSON.
- Optionally uses an OpenAI model to interpret the request and invoke the study-plan tool through function calling.

## Important distinction

**Basic planner mode works without an AI model.** It is a deterministic Python tool and a useful first teaching step.

**LLM-powered agent mode** uses an OpenAI model to request the tool call. The Python application validates the tool name and executes the local function; it does not run arbitrary code generated by the model.

## Requirements

- Python 3.10 or newer
- Internet access to install packages
- Optional: an OpenAI API key for LLM-powered mode

## Run on Windows

1. Extract the ZIP.
2. Double-click `run_windows.bat`.
3. The script creates a virtual environment, installs dependencies, and starts the app.
4. Open the local URL printed in the terminal (usually `http://localhost:8501`).

If you prefer manual setup in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

If PowerShell blocks virtual-environment activation, use the included `run_windows.bat` instead.

## Enable OpenAI mode

1. Set the `OPENAI_API_KEY` environment variable before starting the app. Do not paste the key into source code or commit it to Git.
2. Example for the current PowerShell window:

```powershell
$env:OPENAI_API_KEY = "your_api_key_here"
python -m streamlit run app.py
```

3. Select **LLM-powered agent (OpenAI API)** in the sidebar.

An API key and account access are required; API usage may incur charges. The model name in `study_agent.py` is `gpt-4o-mini`; change it if your account uses a different supported model.

## How the agent flow works

1. The student enters a goal and study details in Streamlit.
2. In basic mode, the Python planner directly creates a schedule.
3. In LLM mode, the app sends the request and tool schema to the model.
4. The model requests the `create_study_plan` tool.
5. The app validates the tool name and arguments, then calls the local Python function.
6. The app displays and lets the student download the result.
